Política de Privacidad de DeusEx v3

Última actualización: noviembre de 2026 · Versión aplicable: DeusEx v3.0.0

Resumen ejecutivo: DeusEx v3 se ejecuta íntegramente en tu equipo Windows 11. No operamos servidores propios que recolecten, almacenen o vendan tus conversaciones, archivos, correos, credenciales ni telemetría. Este portal web es un sitio estático informativo y puente OAuth/Setup Sync que solo se comunica con tu propio equipo en http://127.0.0.1:8888.

1. Arquitectura Local-First y Almacenamiento de Datos

Todos los datos generados o configurados por el usuario se almacenan exclusivamente en el directorio local %LOCALAPPDATA%\DeusEx\:

  • Configuración general (settings.json): preferencias de interfaz, tema, perfiles, permisos y módulos activos. Nunca guarda contraseñas, claves API ni tokens OAuth.
  • Base de datos local (deusex.db): historial de chat, memoria adaptativa, temporizadores, rutinas y auditoría de acciones en SQLite WAL.
  • Secretos aislados (.env y secrets/): las claves API proporcionadas por el usuario (por ejemplo, Gemini o Discord) se escriben de forma atómica en .env, y los tokens OAuth 2.0 PKCE se guardan exclusivamente en secrets/. Ambos se excluyen automáticamente de respaldos .zip, logs de diagnóstico y repositorios Git.

2. Google API Services User Data Policy — Limited Use Disclosure

Google API Services User Data Policy (Limited Use): DeusEx v3's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

En particular, cuando conectas voluntariamente tu cuenta de Google mediante OAuth 2.0 PKCE:

  • Uso estrictamente acotado al usuario: los datos de Google Workspace (Gmail, Google Calendar, Google Tasks, Google Drive, Google Docs) y YouTube Music se consultan o modifican únicamente para ejecutar acciones solicitadas explícitamente por ti dentro de DeusEx v3.
  • Cero transferencia a servidores de terceros no autorizados: los tokens de acceso y refresco permanecen exclusivamente en %LOCALAPPDATA%\DeusEx\secrets\google_oauth.json. No se venden, alquilan ni comparten con anunciantes, intermediarios ni servidores de DeusEx.
  • Prohibición de entrenamiento de IA generalizada: los datos obtenidos desde las APIs de Google Workspace jamás se utilizan para entrenar modelos generalizados de inteligencia artificial ni aprendizaje automático.
  • Freno físico de acciones sensibles (SafetyGate): acciones críticas como enviar correos o eliminar eventos/tareas requieren tu confirmación explícita en pantalla antes de ejecutarse.

3. Integraciones y Proveedores Externos Elegidos por el Usuario

Cuando activas de forma voluntaria un módulo o proveedor, DeusEx v3 realiza conexiones directas desde tu PC hacia el servicio correspondiente (sin pasar por servidores de DeusEx):

  • Proveedores de IA (Gemini u otros configurados por ti): reciben solo el texto, audio o captura puntual que tú envías para responder a tu solicitud. En Modo Privacidad (Ctrl+Shift+P), la memoria adaptativa, el portapapeles y la Guía Live quedan congelados.
  • Servicios de clima, noticias y búsqueda: las consultas de clima usan Open-Meteo (tier gratuito sin clave) y las noticias usan fuentes RSS públicas.
  • Spotify, TIDAL, Discord, WhatsApp y Red Local: los módulos inician desactivados por defecto (arquitectura Zero-Base) y se comunican únicamente con sus APIs oficiales o dispositivos en tu propia red doméstica.

4. Seguridad del Portal Web (Callback OAuth y Setup Sync)

Este portal alojado en GitHub Pages es 100% estático (HTML, CSS y JavaScript del lado del cliente). No instala cookies de rastreo ni analítica de terceros. El puente callback.html valida el parámetro anti-CSRF state y aplica una lista blanca estricta que solo permite reenviar códigos OAuth PKCE y envíos Setup Sync hacia http://127.0.0.1:<puerto>, bloqueando cualquier intento de redirección hacia dominios externos (protección anti Open-Redirect).

5. Control, Revocación y Eliminación de Datos

  • Desconexión inmediata: puedes desvincular tu cuenta de Google en 1 clic desde Integraciones dentro de DeusEx v3, lo que elimina inmediatamente secrets/google_oauth.json de tu equipo.
  • Revocación en Google: también puedes revocar el acceso en cualquier momento desde Permisos de tu Cuenta de Google .
  • Eliminación total: borrar la carpeta %LOCALAPPDATA%\DeusEx\ elimina de forma permanente el historial, memorias, configuraciones y credenciales locales.

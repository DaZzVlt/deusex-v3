Política de Privacidad — DeusEx v3

Última actualización: 25 de noviembre de 2026 · Versión aplicable: DeusEx v3.0.0

DeusEx v3 es un asistente personal de escritorio para Windows 11 con arquitectura 100 % Local-First. La aplicación se ejecuta directamente en el computador del usuario y no opera ningún servidor central propio que reciba, almacene o procese tus correos, calendarios, tareas, archivos o credenciales. Este portal web estático solo actúa como documentación y puente local hacia http://127.0.0.1:8888.

1. Datos a los que accede DeusEx v3 y cómo se utilizan

El acceso a cuentas externas es completamente opcional y solo se activa cuando el usuario inicia sesión explícitamente mediante OAuth 2.0 PKCE desde la sección de Integraciones de la aplicación.

1.1 Google Workspace y YouTube Music (Google APIs)

  • Perfil básico (openid, email, profile): Mostrar qué cuenta de Google está vinculada dentro de la interfaz local de DeusEx v3.
  • Gmail lectura (gmail.readonly): Leer, buscar y resumir correos no leídos únicamente cuando el usuario lo solicita por texto o voz.
  • Gmail redacción y envío (gmail.compose): Crear borradores solicitados por el usuario y enviar correos electrónicos solo después de una confirmación física explícita acción por acción en el panel de seguridad local (SafetyGate).
  • Google Calendar (calendar): Consultar la agenda diaria y crear, modificar o eliminar eventos bajo instrucción directa del usuario (el borrado requiere confirmación en SafetyGate).
  • Google Tasks (tasks): Listar, crear, completar, actualizar o eliminar tareas personales bajo solicitud del usuario (el borrado requiere confirmación en SafetyGate).
  • Google Drive y Google Docs (drive.file): Buscar y descargar archivos accesibles por la aplicación y crear documentos de Google Docs a partir de investigaciones o notas generadas localmente.
  • YouTube Data API (youtube.readonly): Acceso estrictamente de solo lectura para listar las playlists de YouTube Music del usuario y reproducir pistas localmente.

1.2 Otros servicios opcionales (Spotify y TIDAL)

  • Spotify (OAuth 2.0 PKCE): Control de reproducción, consulta de pista activa, lectura de playlists privadas y Canciones que te gustan.
  • TIDAL (OAuth 2.0 PKCE): Lectura de perfil básico y playlists para búsqueda y reproducción local.

2. Almacenamiento local y seguridad de credenciales

Todos los tokens OAuth (secrets/google_oauth.json), claves API (.env), preferencias (settings.json), memoria adaptativa y registros (deusex.db) permanecen exclusivamente en el equipo del usuario bajo la carpeta local de datos de la aplicación (%LOCALAPPDATA%\DeusEx\), y se excluyen automáticamente de respaldos .zip y diagnósticos. El flujo OAuth 2.0 PKCE utiliza un servidor temporal limitado estrictamente a la interfaz local 127.0.0.1 con validación anti-CSRF (state) y protección anti Open-Redirect que se apaga al cerrar la aplicación.

3. Compartición de datos y uso con modelos de IA

  • DeusEx v3 no vende, alquila ni comparte datos de usuario de Google con terceros, anunciantes ni corredores de datos.
  • Los datos obtenidos de Google Workspace no se utilizan para entrenar modelos generalizados de inteligencia artificial o aprendizaje automático (AI/ML).
  • Cuando el usuario solicita resumir o redactar contenido usando un proveedor de IA configurado con su propia clave API, solo se envía el fragmento estrictamente necesario para responder esa solicitud puntual. En Modo Privacidad (Ctrl+Shift+P), la memoria adaptativa, el portapapeles y la Guía Live quedan congelados.

4. Retención, desconexión y eliminación de datos

DeusEx v3 no mantiene copias en servidores externos. Puedes revocar y eliminar tus datos en cualquier momento:

  1. Desde la aplicación: Ve a Integraciones y Dispositivos y haz clic en Desconectar en Google, Spotify o TIDAL para borrar inmediatamente los tokens locales.
  2. Desde tu cuenta de Google: Revoca el acceso de DeusEx v3 en myaccount.google.com/permissions.
  3. Eliminación total: Borra la carpeta local %LOCALAPPDATA%\DeusEx\ para eliminar cualquier dato o caché persistida en tu PC.

5. Google API Services User Data Policy — Limited Use Disclosure

DeusEx v3's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

DeusEx v3 does not use Google Workspace APIs to develop, improve, or train generalized AI and/or ML models. All Google user data is processed solely to provide user-facing personal assistant features requested directly by the user on their own local device.

6. Contacto

Si tienes dudas sobre privacidad o manejo de datos, puedes escribir al responsable del proyecto mediante el repositorio oficial en github.com/dazzvlt/deusex-v3 o al correo de contacto publicado en la pantalla de consentimiento OAuth de la aplicación.
